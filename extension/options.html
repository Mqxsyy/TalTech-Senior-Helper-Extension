Veebiabilise seaded

See leht on pereliikmele, kes abilise seadistab.

Tehisaru teenus
Claude API võti

Loo võti aadressil console.anthropic.com. Võti salvestatakse ainult selle arvuti Chrome'i.

Gemini API võti

Loo tasuta võti aadressil aistudio.google.com. Võti salvestatakse ainult selle arvuti Chrome'i. Tasuta küsimuste arvu näed samal lehel.

Teksti suurus abilises
Hääl

Sellel arvutil pole eestikeelset ettelugemise häält, seega vastuseid ette lugeda ei saa.

Häälega küsimiseks on vaja üks kord mikrofoni luba. Vajuta „Luba mikrofon“ ja nõustu Chrome'i küsimusega.

Veebilehed, kus abiline on välja lülitatud

Üks veebileht rea kohta, näiteks swedbank.ee. Abiline ei loe neid lehti ega saada neid kuhugi.

Abilise parandamine

Kui see on sees, jätab abiline iga vastuse koos lehe pildiga selle arvuti meelde. Nii saab hiljem vaadata, kus abiline eksis. Midagi ei saadeta kuhugi. Kastidesse kirjutatud tekst on pildil kinni kaetud, aga muu lehel olev on näha.
