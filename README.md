## Requirements

- Chromium based browser
- Node.js 18+
- AI API key
    - Gemini (free): https://aistudio.google.com/apikey
    - Claude (paid): https://console.anthropic.com


## Installation & Usage

1. Clone repo & build extension:

   ```bash
   git clone git@github.com:Mqxsyy/TalTech-Senior-Helper-Extension.git
   cd TalTech-Senior-Helper-Extension
   npm install
   npm run build
   ```

2. Open `chrome://extensions`, turn on **Developer mode** (top right), click **Load unpacked**, and pick the `TalTech-Senior-Helper-Extension/extension` folder
3. Go to extension options, choose one of the **Tehisaru teenus**, paste the api key, click **Kontrolli võtit** and wait for „Võti töötab.“, then click **Salvesta**
4. Open the extension by clicking on it from the extensions list
